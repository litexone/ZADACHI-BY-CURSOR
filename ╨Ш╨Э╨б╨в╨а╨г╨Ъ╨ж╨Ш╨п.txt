КАК ПОЛУЧИТЬ APK (бесплатно, без установки программ)

Нужен только аккаунт на github.com (регистрация бесплатная).

1. Зайдите на github.com -> кнопка "+" вверху справа -> New repository.
   Название любое, например zadachi. Public. Нажмите Create repository.

2. Распакуйте архив GeneratorZadach-Android.zip на компьютере.

3. На странице нового репозитория нажмите "uploading an existing file".
   Перетащите в окно ВСЁ СОДЕРЖИМОЕ распакованной папки (не саму папку, а то, что внутри:
   app, gradle, .github, gradlew, build.gradle и т.д.).
   ВАЖНО: папка .github должна загрузиться (у неё точка в начале; на Windows включите
   показ скрытых файлов, если её не видно). Нажмите Commit changes.

4. Откройте вкладку Actions. Сборка "Build APK" запустится сама (если нет: Build APK -> Run workflow).
   Подождите 3-6 минут, пока рядом не появится зелёная галочка.

5. Нажмите на завершённую сборку -> внизу раздел Artifacts -> скачайте GeneratorZadach-apk
   (это ZIP, внутри app-debug.apk).

6. Перекиньте app-debug.apk на телефон (почта, Telegram, USB), откройте его.
   Android попросит разрешить установку из этого источника - разрешите.
   Приложение называется "Задачи 5–9".

Если сборка красная: откройте её, скопируйте текст ошибки и пришлите мне - исправлю.

ВАРИАНТ ЧЕРЕЗ ANDROID STUDIO
Откройте папку проекта в Android Studio -> Build -> Build Bundle(s)/APK(s) -> Build APK(s).
APK будет в app/build/outputs/apk/debug/.

ЗАМЕЧАНИЯ
- Кнопка "Печать" на телефоне не работает (ограничение Android WebView); используйте "Копировать".
- Это debug-APK: ставится на телефон напрямую, но в Google Play в таком виде не публикуется.
